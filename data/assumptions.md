# 假设登记表

> 本文件是 `src/` 下每一个非 `data/` 数据常量的**唯一出处**。
> 代码中不允许出现未登记的魔法数字。
> 口径纪律与本项目其他部分一致：**查不到就写「未查到」，不用看起来合理的数字替代。**

## A · 需求结构化

### A-01 需求点分类
| 需求点类型 | 识别依据 | 说明 |
|---|---|---|
| `migration` | 迁移 / 上云 / 搬 / 统一管理 | 资源迁入类 |
| `ops_efficiency` | 管理麻烦 / 运维 / 效率低 | 管理体验类 |
| `scheduling` | 排队 / 等待 / 调度 / 队列 | 作业调度类 |
| `competitor` | 对标 / 友商 / 华为 / 阿里 / 腾讯 / 比较 | 竞争认知类 |
| `compliance` | 政企 / 涉密 / 机房 / 不上公有云 | 合规与数据驻留类 |
| `cost` | 贵 / 降本 / 预算 | 成本类 |
| `performance` | 慢 / 卡 / 性能 | 性能类 |
| `sla` | SLA / 可用性 / 稳定 | 服务等级类 |

> 分类是**多标签**：一条原始诉求常同时命中多类
> （例：「虚拟机太多管理麻烦，希望统一管理」同时命中 `ops_efficiency` 与 `migration`）。

### A-02 需求说明书必填字段
| 字段 | 缺失时处理 |
|---|---|
| 客户行业 | 填「待补充」 |
| 业务场景描述 | **必填，缺失即拒绝生成说明书** |
| 需求点清单 | **必填** |
| 约束条件 | 填「未提取到」，不推测 |
| 优先级 | 填「待确认」 |
| 期望指标 | 填「未提取到」——**不编数字** |
| 数据驻留要求 | 填「未提取到」 |

## B · 竞品矩阵

### B-01 五层产品定义
| 层 | 定义 | 对标维度 |
|---|---|---|
| **IaaS** | 基础设施即服务：计算、存储、网络 | 计算 / 存储 / 网络 / GPU 算力 / HPC 算力 |
| **PaaS** | 平台即服务：数据库、容器、大数据、AI 平台 | 容器 / 数据库 / 大数据 / AI 平台 / Serverless / 检索 |
| **DAAS** | 数据即服务：数据仓库、数据湖、数据治理 | 数据仓库 / 数据治理 / AI 训练推理平台 |
| **MASS** | 异构算力即服务：高端计算、智算集群、超节点 | 高端计算机 / 智算集群 |
| **SaaS** | 软件即服务：应用、办公、行业软件 | 应用类 |

> 五层是**行业通行的云服务分层口径**（IaaS/PaaS/DAAS/MASS/SaaS），
> 不是本项目的自创分类。

### B-02 矩阵覆盖度
| 指标 | 定义 |
|---|---|
| 厂商覆盖率 | 有产品条目的厂商数 / 目录厂商总数 |
| 层覆盖率 | 有产品条目的层数 / 5 |
| 能力域覆盖率 | 有产品条目的能力域数 / 全部能力域数 |
| **空白项** | 显式列出「该厂商在该层未查到公开产品」 |

> **空白项是输出的一部分，不是缺陷。** 竞品对标的价值一半在于知道对方有什么，
> 一半在于知道对方没什么。

### B-03 不做的事
| 不做 | 原因 |
|---|---|
| 优劣评分 / 打分 | 本项目只做产品线认知层面对标，不做评判 |
| 收录价格 | 价格随地域规格折扣变动，无稳定公开口径 |
| 收录 SLA 数字 | 属商业条款，非公开产品能力 |
| 推测未公开的能力 | 查不到就是查不到 |
| 排名与推荐序 | 同上，做排名即等于打分 |

## C · 周月数据报告

### C-01 指标口径
| 指标 | 公式 | 口径来源 |
|---|---|---|
| 需求数 | 期内新增需求条目数 | 逐条计数 |
| 需求类型分布 | 各类型需求数 / 总需求数 | 分类计数 |
| 完整率 | 已填字段数 / 必填字段总数 | 字段级 |
| 平均澄清轮次 | 澄清轮次总和 / 需求数 | **占位待真实记录替换** |
| 竞品对标覆盖度 | 见 B-02 | 本项目定义 |

> **不做业务营收预测、不做用户增长预测** —— 本项目没有业务数据，
> 任何预测数字都只能是编的。报告只覆盖「需求管道自身」的可测量指标。

## D · 明确不做的事

- **不做 Axure/XMind 替代工具**：本项目用**代码生成流程图**（结构化文本 → Mermaid 文本图），
  版本可 diff、样式统一；但不追求像素级原型还原度，那不是本项目的目标。
- **不做私有云产品线的能力推测**：私有制产品**只录公开可查信息**。
- **不做 SLA 数字与价格对比**：属商业条款。
- **不做竞品优劣结论**：只并列客观信息。
- **不做用户画像与需求预测**：无业务数据。
- **不含真实客户信息**：场景为自拟，不影射任何真实项目。
- **不做性能实测**：本项目是需求与对标引擎，不是性能工具。
